# 幻想大陆生灵图鉴 · Fantasy Continent Codex

一座悬浮于夜空之海的幻想大陆。六境——**苍穹 / 碧海 / 林泽 / 遗迹 / 旷野 / 幽域**——本次可见版本收录 23 种虚构生灵，
每只生灵拥有一页自包含的「动态漫画短片 + 物种档案」话页：可播放/暂停、拖动进度、切换章节、
点亮动效印章，还能换上「黑白网点」或「原稿蓝图」印刷滤镜。

另有两位不受境界束缚的「全境种」（浮光天海鲵、曦光游晶兽），在任一境的筛选中都会出现。

此外，还有一款 **8 分钟试玩游戏《星兽纪》**：在旷野、苔林、晶洞三境探索，削弱并捕捉星兽，
用回合制战斗把三道星痕送回夜空。玩法参考石器时代的宠物捕捉与回合制，素材与世界观沿用本图鉴。

## 快速使用

- **玩试玩版**：打开 `index.html`，点「▶ 试玩《星兽纪》」，或直接打开 `幻想大陆-星兽纪.html`。
  单文件、零外部素材（仅 Google Fonts，离线自动回退），键鼠与触屏均可玩，约 8 分钟一段完整短篇。
- **先看序章**：打开 `index.html`，点「观看序章动画 · 54 秒」，或直接打开 `幻想大陆-序章.html`。
  一段纯 Canvas 2D 制作的介绍短片，分「坠星 → 大陆浮现 → 六境巡礼 → 二十页 → 收束」五幕，配程序化环境音（默认静音，可开启）。
- **分享给朋友**：直接发送 `幻想大陆生灵图鉴-单文件版.html`，对方用任意现代浏览器打开即可（序章、试玩与全部话页均已内嵌）。
  点卡片弹出全屏话页/游戏，「← 返回图鉴」/ Esc / 系统返回手势均可关闭；同一时刻只运行一个话页或游戏。
- **本地浏览多文件版**：打开 `index.html`，点击生灵卡片进入各话页，或点试玩入口。
- **在线部署**：仓库 Settings → Pages → 由 `main` 分支根目录部署，即可获得可分享的网址。

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 图鉴首页（唯一编辑源）：夜空星海、极光带、漂浮岛视差、萤火粒子、大陆介绍、试玩入口、六境总览与筛选、23 张生灵导航卡、序章入口 |

## 试玩《星兽纪》

- **一段完整短篇**：风铃营地 → 风蚀红丘 → 苔雨林 → 地脉晶洞，约 8 分钟。没有存档，重开即从头开始。
- **玩法**：探索四张手绘 Canvas 地图；在高草里遇敌，进入回合战斗；把星兽体力压到阈值以下后抛出「星纹藤环」捕获；
  队伍最多 6 只，可换宠、用星技、吃药；三段剧情战各收一只星兽，最后在晶洞安抚暴走的沸泉晶钟兽。
- **操作**：WASD / 方向键移动，空格或 E 互动；战斗中点按钮或按数字键 1–6；T 队伍、C 图鉴、M 声音、H 帮助。
  触屏设备会自动显示方向键与互动按钮。
- **风格**：程序化绘制的Q版星兽、米色纸片战斗 UI、暖色地图、程序化五声音阶音乐；不使用任何图片素材。

## 新增一只生灵

1. 将新话页 `<生灵名>.html` 放入仓库根目录；
2. 在 `index.html` 图鉴区添加对应卡片（`data-realm` 填六境之一：`sky`/`sea`/`forest`/`ruin`/`wild`/`deep`，全境种填 `all`）；
3. 运行 `node build-single.mjs` 重新生成单文件版（脚本自校验内嵌内容逐字节一致、链接完整、语法可解析）。

> 开发者请先读 [HANDOVER.md](HANDOVER.md)：内含话页骨架、验证方法、设计约定与踩坑记录。

## 新增篇交付 · 2026-10-18

新增 **寻泉萤草 / 幽谷聆芽 / 诱光芽蠕**，各为原生 Canvas 2D、25 秒四幕的独立 HTML，保留八项档案与全套交互。使用“新增篇＋名称”标识，不占用用户尚未上传的第 19–50 话编号。

- 三只独立合集：`deliverables/新增三种动态图鉴-单文件版.html`，仅内嵌本次三只。
- 兼容合并版：根目录 `幻想大陆生灵图鉴-单文件版.html`，本次可见的 23 只＋原序章＋《星兽纪》试玩。
- 浏览器验证：`qa/verify-new-creatures.cjs`、`qa/verify-geometry.cjs`、`qa/verify-packages.cjs` 使用 Playwright 与系统 Chromium（`/usr/bin/chromium`）。先在仓库根目录启动 `python3 -m http.server 8765 --bind 127.0.0.1`，再运行三个脚本。报告和截图由脚本生成，随 Library 交付包留存，不提交至仓库。
- 独立合集源首页：`extras/新增篇首页.html`。重建命令：

```bash
node build-single.mjs
node build-single.mjs --index=extras/新增篇首页.html --out=deliverables/新增三种动态图鉴-单文件版.html
```

本环境仅找到 23 只已上传话页，用户尚未上传的其余内容未出现在仓库中，尚未整合完整 50 种。原有话页与序章未改动；序章中的“二十页”保留为原版历史内容。新增篇与《星兽纪》均按用户授权合并至 `main`。
